# 自作Skillsの原本

MVP入力検査、MARBLE実行準備、計算結果整理、研究知識への昇格など、繰り返し使う手順をSkillとして資産化する場所です。

各Skillは独立したディレクトリと `SKILL.md` を持たせます。この場所はソース・オブ・トゥルースであり、実際に利用する際は各Codex環境が認識する標準のSkill領域へ導入します。

候補:

- `mvp-input-review/`
- `mvp-run-preparation/`
- `marble-result-analysis/`
- `promote-research-knowledge/`

利用可能な原本:

- `team-sync-check/` — 複数PC間でteamリポジトリのGit状態と同期リスクを読み取り専用で確認する
