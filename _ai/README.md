# AI運用領域

`_ai/` は実際の研究作業をする場所ではなく、AIにどのように作業してもらうかを管理する制御領域です。

- `rules/`：全体運用の詳細
- `templates/project/`：継続的なプロジェクトを開始するときのひな形
- `prompts/`：複数プロジェクトで再利用する共通プロンプト
- `skills-src/`：自作Skillの原本。利用環境への導入は別途行う
- `mcp/`：MCP設定例とセットアップ手順。秘密情報は禁止
- `bootstrap/`：別PCでワークスペースを再現するための説明

テンプレート自体の中では作業しません。新しい継続プロジェクトを始めるとき、テンプレートを `work/projects/<project>/` に複製してから内容を書き換えます。
