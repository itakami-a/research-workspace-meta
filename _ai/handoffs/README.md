# Device Handoffs

Codexの会話履歴やローカル観測結果は、別PCのCodexへ自動共有されません。このディレクトリは、次の作業に必要な結論だけをGitで共有するための場所です。

## ルール

- 端末ごとに一つのファイルを使う。例: `desktop-withd.md`、`notebook-withd.md`
- 同じhandoffを別端末で編集しない
- 長い会話記録、全コマンド出力、生ログは書かない
- 「完了」「現在の状態」「次の一手」「承認が必要な操作」だけを残す
- 同期・移行・未完了事項に関係する作業を終えたときだけ更新する

## 開始時

`AGENTS.md`、`.local/DEVICE.md`、自分のhandoff、`git status -sb` を確認します。同期操作はユーザーが明示的に依頼した場合だけ行います。
